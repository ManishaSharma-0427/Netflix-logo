# Netflix-logo
A simple and visually focused Netflix logo webpage built using HTML. This project recreates the iconic Netflix branding with a clean layout and attractive design, demonstrating fundamental HTML structure, styling, and web presentation. It is beginner-friendly and serves as a practice project for learning frontend development.
